# LifeInstruct Bible

**Scripture to guide how we live.** A personal custom Scripture reader from Benighter, inspired by 2 Timothy 3:16.

[Download the latest Android release](https://github.com/Benighter/LifeInstruct-Bible-Releases/releases/latest)

This channel contains signed app downloads, checksums, update manifests and release notes. Editable source stays private. Updates are checked when the app is opened and while you read; Android asks you to approve installation.

Original engine, translation and framework credits are preserved inside the app. Publisher access rules apply to licensed resources.
